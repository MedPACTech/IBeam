# IBeam.Management.Licensing

Read the root .agent/implementation-guide.md. This optional integration owns typed Management orchestration over native Licensing services; keep Identity/Billing dependencies out and APIs thin. Native status writes must atomically compare exact versions and commit immutable same-intent receipts. Missing/incompatible providers fail closed. Volatile native storage is explicit Development/Testing only. Restore requires a target-owned policy and a native runtime-eligible original status; never create entitlements, memberships or roles. Authorize against a compatible live Management boundary before native reads/writes and recheck after replies. Unknown replies never retry a mutation. Audit metadata only through the Management executor; no licence/provider/profile DTO snapshots. Generic HTTP dispatch remains a separate explicit registration, not an arbitrary URL/body proxy.
