# IBeam.Management.Licensing

Read the root .agent/implementation-guide.md. This optional integration owns typed Management orchestration over native Licensing services; keep Identity/Billing dependencies out and APIs thin. Native status writes must atomically compare exact versions and commit immutable same-intent receipts. Missing/incompatible providers fail closed. Volatile native storage is explicit Development/Testing only. Restore requires a target-owned policy and a native runtime-eligible original status; never create entitlements, memberships or roles. Authorize against a compatible live Management boundary before native reads/writes and recheck after replies. Unknown replies never retry a mutation. Audit metadata only through the Management executor; no licence/provider/profile DTO snapshots. Generic HTTP dispatch remains a separate explicit registration, not an arbitrary URL/body proxy.

IBM-0128: seat reads/assign/unassign are independent explicit capabilities. Preserve native active-licence/capacity/customer-subject policy, one exact licence/seat aggregate revision across all writers, and immutable scope/intent receipts. A replay never consumes another seat or revokes a replacement. No membership/role/tenant status changes or customer impersonation. Bound snapshots to 2,000 safe assignments, never expose native subject/profile/provider text, and require durable production storage. Unknown replies only reconcile through authorized read-only lookups. See docs/management/seat-management.md.

IBM-0129: registered operations use the separate optional signed target/client protocol, persisted live machine grants and explicit live human assignments. Preserve distinct proof type, fixed descriptor fingerprints/resources, nonce replay store, fresh discovery and uncertain-write read-only recovery. Never auto-upgrade borrowed grants or log payloads/keys. See docs/management/registered-operation-dispatch.md.
