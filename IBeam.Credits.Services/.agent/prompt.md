# IBeam.Credits.Services

Read the root .agent/implementation-guide.md. Services own credit account, policy, reservation, settlement and recovery rules; persistence belongs behind the native store ports. Keep Credits independently usable and preserve API -> Services -> Repository boundaries. Route custom operations through IServiceOperationExecutor, bind every account/bucket/reservation to its tenant, and preserve stable operation identities and concurrent balance/reservation guarantees. Do not treat commercial Billing state or a customer role as a runtime credit grant. Never log credentials, raw provider errors or consumer payloads. Test denied policies, concurrent use, cancellation, failed-operation reservation release and exact recovery in the existing Credits/Licensing suites. Keep the README, public registrations and packaged agent guide accurate.
