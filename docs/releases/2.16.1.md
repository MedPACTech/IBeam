# IBeam 2.16.1 — management invitation URL compatibility

Patch candidate based on the 2.16.0 default-branch release. This release includes only the management invitation URL fix; development ownership/lifecycle features are excluded.

Management invitation resend, direct customer provisioning and enterprise onboarding now share unpadded base64url token generation. All three preserve 32 random bytes, SHA-256 hashing of the raw token string, and existing encrypted delivery recovery. Existing stored tokens are not rewritten or rehashed.

New links contain only letters, digits, hyphen and underscore. Windows IIS consumer hosts can enable `system.webServer/security/requestFiltering allowDoubleEscaping="true"` to accept encoded-plus paths from older invitations while retaining their ASP.NET Core Module configuration. Old encoded-slash links require resend after upgrading. No production token or invite is changed by the package upgrade.

Align IBeam packages at 2.16.1 after the approved release is published. Prepare feature PRs into development, validate the isolated patch in test, and follow `docs/release-strategy.md`. User approval is required before pushing, merging, publishing or deployment. Production rollout order: IBeam package, Qurvia API, Qurvia APP; the user then resends affected invitations from the Portal Account page.
