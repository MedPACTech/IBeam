# IBeam.Licensing.Credits

Read the root .agent/implementation-guide.md. This optional integration coordinates native licence gates and credit policy/reservation services; keep Licensing and Credits independently usable. Services own authorization, rules and orchestration through IServiceOperationExecutor. Preserve tenant/subject/account scope, check licence/seat eligibility before executing work, and release reservations on failed operations without hiding the original exception. Do not make Billing state a runtime grant or move persistence into the coordinator. Do not log credentials, request/response bodies or consumer profiles. Test policy rejection, cancellation, reservation recovery and cross-tenant/account isolation in IBeam.Tests.Licensing. Keep this guide packaged with the existing README and root implementation guide.
